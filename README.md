# React Sortable Tree

A modern, type-safe React component for drag-and-drop sortable representation of hierarchical data. Built with TypeScript, React 19, Tailwind CSS, Zod, and Zustand.

## Features

- 🔄 Drag-and-drop functionality for nested data
- 📱 Fully responsive design
- 🎨 Customizable themes with Tailwind CSS
- 🔒 Type-safe with TypeScript
- 📊 State management with Zustand
- ✅ Data validation with Zod
- 🎯 Virtualized rendering for large datasets
- 🎨 Modern UI with Tailwind CSS

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS 4
- Zod (for data validation)
- Zustand (for state management)
- Vite (for development and building)
- Vitest (for testing)
- ESLint & Prettier (for code quality)

## Development Setup

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start development server:
   ```bash
   npm run dev
   ```
4. Run tests:
   ```bash
   npm run test
   ```
5. Build the library:
   ```bash
   npm run build
   ```
